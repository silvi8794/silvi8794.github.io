E-commerce API

Una API REST escalable diseñada con arquitectura dirigida por eventos (EDA) y comunicación en tiempo real mediante WebSockets. Este proyecto integra pasarelas de pago como Mercado Pago y automatiza la validación administrativa de pagos mediante el uso de Inteligencia Artificial (Google Gemini), extrayendo y verificando datos bancarios de forma autónoma. Incluye gestión completa de catálogos jerárquicos, control de stock por variante y seguridad avanzada con RBAC y JWT, todo bajo un enfoque de código limpio y tests automatizados con Jest.
